# yoniverseproductions.com - developer handoff

Live at https://yoniverseproductions.com. Hosted on Vercel.

## What this is

The whole site is generated by one Python file, `build_site.py` (about 2,500 lines).
There is no framework, no node_modules, no build toolchain. You run the script and it
writes a `deploy/` folder of static HTML. Every page, all CSS, and all inlined assets
come out of that one file.

Requirements: Python 3.9 or newer. Nothing else.

## Build and deploy

    python3 build_site.py web     # writes ./deploy
    ./deploy_github.sh            # builds, then force-pushes ./deploy to gh-pages

**Hosting moved to GitHub Pages on 2026-08-28.** The live site is the `gh-pages`
branch of this repo, served at homeservicestudios.com. `./deploy.sh` is the old
Vercel path and will not work without Vercel CLI auth, which is not set up on the
build machine. Use `./deploy_github.sh`.

## What is not in this archive

**`deploy/`** - the build output. Regenerated every time you run the script, so it was
not worth sending.

**`vid/` is no longer needed.** This document used to say the build would not run
without a 74 MB `vid/` folder. That stopped being true on 2026-08-26, when all 17
clips moved to YouTube. The build emits zero mp4 files now and is correct without it;
`vid/` stays in `.gitignore` only so old local copies do not get committed.

## One file was renamed for email

`api_contact.js.txt` needs to be renamed back to `api_contact.js`. Gmail rejects any
message carrying a `.js` file, including inside a zip, so it could not be sent under
its real name. The build script reads it as `api_contact.js`, so rename it before you
build or the contact form will not be wired up.

## Layout

    build_site.py        the entire site: templates, CSS, copy, page assembly
    data/packages.json   pricing. single source of truth, see note below
    api_contact.js       Vercel serverless function behind the contact form
    deploy.sh            build plus deploy
    CLAUDE.md            the rules this site was built to. read this first
    fonts/               woff2 faces, inlined as base64 at build time
    post/                case study stills and photography
    post_yt/             YouTube thumbnails, webp
    logos/, logos_webp/  client logos
    og/                  per page Open Graph images
    vid/                 NOT INCLUDED, see above
    make_wm.py           watermarking helper, not part of the site build

## Things that will bite you

**Prices are not in the template.** They live in `data/packages.json`. The build fails
on purpose if it finds a hardcoded dollar figure in `build_site.py`. This assertion
exists because prices were previously scattered across pages and drifted out of sync.

**The build asserts on output.** It refuses to emit em dashes or en dashes, and refuses
any non-ASCII byte. If your edit introduces either the build stops. This is intentional.

**`font-display` is `optional`, not `swap`.** Swap caused a 0.18 layout shift on the
hero stats. Changing it back will regress Cumulative Layout Shift from 0.

**The contact form needs an env var.** `BREVO_API_KEY` is set in the Vercel project
settings for Preview and Production. It is not in this archive. The form posts to
Brevo's transactional API and mails info@homeservicestudios.com (switched 2026-08-25).

**Trade and budget lists are duplicated.** The `TRADES` and `BUDGETS` arrays exist in
both `build_site.py` and `api_contact.js` and must stay identical. If they drift, valid
submissions get a 400. This is the one piece of real duplication in the project and it
is worth fixing properly.

**`BOOK_URL` is empty.** While empty, every conversion CTA points at `/contact/#start`.
Set it to a scheduler link and all CTAs across the site repoint automatically.
